# Bienvenue (/docs)

Relift Commerce ajoute à WordPress et WooCommerce ce qu’un catalogue professionnel demande : fiches techniques, comptes pros vérifiés, prix par groupe, devis et commandes avec conditions. Tout se règle dans l’administration de votre site, sans extension B2B tierce.

Cette documentation s’adresse à l’équipe qui fait vivre le site : responsable catalogue, commercial, administrateur.

## Ce que la documentation couvre [#ce-que-la-documentation-couvre]

Chaque page décrit une fonction **livrée** : ce qu’elle fait, où la trouver dans l’administration, ce qu’il faut régler. Les pages de référence listent les clés de configuration, les commandes et les points d’extension pour les équipes techniques.

<Callout title="Vocabulaire">
Dans l’administration, le menu **Catalogue** est le catalogue de produits WooCommerce, **Clients pros** la liste des comptes, **Réglages** l’écran Relift. L’interface suit ce vocabulaire plutôt que celui de WordPress.
</Callout>
