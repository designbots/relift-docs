# Documents techniques (/docs/catalogue/documents)

L’onglet **Documents** de la fiche catalogue est un tableau : une ligne par document.

| Colonne | Rôle |
|---|---|
| Type | Fiche technique, notice de pose ou d’utilisation, FDS, DoP, FDES / PEP, certificat ou avis technique, plan ou schéma, garantie, autre |
| Fichier | Fichier de la médiathèque (pdf, zip, dwg, ifc, rfa, jpg, png) |
| ou adresse (CDN) | Adresse du fichier s’il est hébergé ailleurs |
| Version | Par exemple `v3` |
| Date | Date de publication |

<Callout title="Fichier ou adresse">
Renseignez l’un ou l’autre. L’adresse sert aux documents hébergés sur un CDN ou chez le fabricant.
</Callout>

## Ce que ça produit [#ce-que-ça-produit]

- Les documents s’affichent sur la fiche par les modèles du thème.
- Ils sont décrits dans les données structurées de la page.
- Les types exigés par la configuration comptent dans la [complétude](/docs/catalogue/completude) : par défaut, la fiche technique.

## Bonnes pratiques [#bonnes-pratiques]

- Nommez les fichiers de façon lisible (`fiche-technique-fenetre-pvc.pdf`).
- Mettez à jour la **version** et la **date** quand un document change, plutôt que d’ajouter une seconde ligne.
- Un même PDF peut être réutilisé sur plusieurs produits depuis la médiathèque.
