Configuration (client.json)

Les différences entre clients passent par la configuration, jamais par une copie du code. Ordre de priorité : valeurs par défaut, puis wp-content/relift/client.json, puis les réglages de l’administration, puis le filtre relift/config. Les chemins listés dans locked sont en lecture seule dans l’administration.
