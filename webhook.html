Configuration (client.json)

Webhook signé

Relift peut notifier un outil d’automatisation (Make, Boost.space, n8n, votre CRM) à chaque événement important. L’envoi est un POST JSON, signé, parti à la fin de la requête pour ne pas ralentir le visiteur.

Activer

  1. Définir le secret dans wp-config.php (jamais dans un dépôt ni un e-mail) :
    define('RELIFT_WEBHOOK_SECRET', 'une-longue-valeur-aléatoire');
  2. Renseigner l’adresse de réception dans automation.webhook.url. En production, elle doit commencer par https://.
  3. Choisir les événements dans automation.webhook.events (tous actifs par défaut).

Sans secret, aucun envoi n’est fait et l’échec est inscrit au journal d’activité.

Événements

Événement Quand
quote_created demande de devis reçue
pro_signup demande de compte pro
pro_approved compte pro validé
pro_refused compte pro refusé

Contenu

{
  "event": "quote_created",
  "site": "https://exemple.fr",
  "sent_at": "2026-11-25T13:00:00+00:00",
  "data": {
    "quote_id": 123,
    "contact": { "company": "…", "name": "…", "email": "…", "phone": "…" },
    "lines": [ { "sku": "…", "name": "…", "qty": 2 } ],
    "consent_at": "…",
    "source": "…"
  }
}

Le contenu est volontairement minimal : aucun prix (ils peuvent être réservés), les coordonnées de la personne et la date de son consentement.

Pour les événements de compte (pro_*), data contient user_id, contact, group, status et consent_at.

Vérifier la signature

Chaque envoi porte deux en-têtes : X-Relift-Event et X-Relift-Signature, de la forme t=<horodatage>,v1=<signature>. La signature est un HMAC-SHA256 de <horodatage>.<corps brut> avec votre secret. Vérifiez-la, et refusez les envois dont l’horodatage est trop ancien.

$entete = $_SERVER['HTTP_X_RELIFT_SIGNATURE'] ?? '';
parse_str(str_replace(',', '&', $entete), $p);   // t, v1
$corps = file_get_contents('php://input');
$attendu = hash_hmac('sha256', $p['t'] . '.' . $corps, $secret);
if (!hash_equals($attendu, $p['v1'] ?? '') || abs(time() - (int) $p['t']) > 300) {
    http_response_code(401); exit;
}

Répondez avec un code 2xx pour confirmer la réception. Un autre code est inscrit au journal d’activité.
